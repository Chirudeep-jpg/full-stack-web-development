## 📌 Repository Overview

This repository serves as a centralized archive for academic coursework, hands-on lab experiments, modular coding exercises, assignments, and assessment submissions spanning modern full-stack web development technologies (HTML5, CSS3, modern JavaScript ES6+, Node.js, Express.js, MongoDB/Mongoose, and React).

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.x or later)
- [MongoDB](https://www.mongodb.com/) (Local Community Server or MongoDB Atlas cluster)
- [Git](https://git-scm.com/)

### Quick Run Guide (Week 03 & 04 Backend)
`ash
# Navigate to experiment directory
cd 01-observation-and-record/week-03-node-and-express-js/src

# Install dependencies
npm install

# Start the server
node server.js
`
